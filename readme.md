# Juan Hurtado Web Portfolio

## About This Project

This project is a personal web portfolio that I created to showcase information about myself, my skills, interests, and some of the projects I have worked on. The website includes a home page, projects page, and contact page that are all connected through a navigation menu. Throughout the project, I used HTML to create the structure and content of each page and CSS to customize the colors, spacing, fonts, layout, and overall appearance of the website. I also learned how to use Flexbox and CSS Grid to organize content and make the website responsive so that it can be viewed properly on desktop computers, tablets, and mobile devices. I added features such as project cards, images, hover effects, and a contact form to make the website more organized and interactive. Finally, I learned how to upload my files to GitHub and use GitHub Pages to publish my portfolio as a live website. Overall, this project allowed me to take the different skills I learned throughout the course and combine them into one complete website that I can continue improving as I learn more about web development.

## What I Learned

* How to use HTML to create and organize the structure of a website.
* How to use CSS, Flexbox, and Grid to style pages and create responsive layouts.
* How to publish and maintain a website using GitHub and GitHub Pages.

## Next Steps

If I had more time, I would add JavaScript to make my portfolio more interactive. I would like to add features such as form validation, interactive buttons, and animations. I would also like to learn more about frameworks that could help me build more advanced websites in the future.
